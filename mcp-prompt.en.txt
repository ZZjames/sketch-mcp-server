# Sketch MCP Server Tool Usage Guide

**🚨 Must strictly follow the step-by-step process, do not skip steps to generate code directly!**

## 📋 Basic Workflow
1. **Load File** - `loadSketchByPath`
2. **Get Structure** - `getDocumentStructure` or `getNodesSummary`
3. **Get Details as Needed** - Choose appropriate tools
4. **Generate Code** - Based on real data

## 🛠️ Core Tools

### 📁 File Loading
- `loadSketchByPath` - Load Sketch file
- `loadSketchByConfig` - Load configuration object

### 📊 Document Structure
- `getDocumentStructure` - Get document structure (🚀 Optimized)
- `getPageStructure` - Get page structure
- `listPages` - List all pages

### 🎯 Node Query
- `getNodesSummary` - Smart summary (🚀 New, 80-90% Token reduction)
- `listNodes` - List nodes
- `listNodesByPage` - List nodes by page
- `findNodesByName` - Find by name

### 🔍 Detailed Information
- `getNodeInfo` - Single node information
- `getMultipleNodeInfo` - Batch node information
- `getNodePosition` - Node position

### 🔄 Symbol Components
- `getSymbolMasters` - All Symbol Masters
- `getSymbolInstances` - All Symbol Instances
- `getSymbolMasterBySymbolID` - Find by ID
- `getSymbolInstanceStyles` - Instance styles

### 🎨 Visualization
- `renderNodeAsBase64` - Render as image

## 🚀 Token Optimization Strategy

### Data Volume Comparison
| Tool/Mode | Token Reduction | Use Case |
|-----------|----------------|----------|
| `getNodesSummary` | 80-90% | Initial analysis |
| `getDocumentStructure`(summary) | 70-85% | Quick overview |
| `getDocumentStructure`(filtered) | 30-50% | Structure analysis |

### Recommended Workflow

**Phase 1: Quick Analysis (Highly Recommended)**
```json
{
  "name": "getNodesSummary",
  "arguments": {
    "groupBy": "type",
    "includeStats": true,
    "maxSamples": 3
  }
}
```

**Phase 2: Structure Analysis (As Needed)**
```json
{
  "name": "getDocumentStructure",
  "arguments": {
    "fields": ["id", "name", "type", "children"],
    "maxDepth": 2
  }
}
```

**Phase 3: Detailed Information (As Needed)**
```json
{
  "name": "getMultipleNodeInfo",
  "arguments": {
    "nodeIds": ["key-node-ID"]
  }
}
```

## 📝 Complete Example

### 🚫 Strictly Prohibited
- Skip loading steps

### ✅ Best Practices
- Prioritize summary tools
- Get detailed information as needed
- Use field filtering wisely
- Leverage Symbol tools
- Use visualization when appropriate

### 🔧 Optimization Parameters

**getDocumentStructure optimization**:
- `summaryMode`: true - Summary mode
- `fields`: ["id", "name", "type"] - Specify fields
- `excludeFields`: ["style", "position"] - Exclude fields
- `maxDepth`: 2 - Limit depth

**getNodesSummary parameters**:
- `groupBy`: "type"|"style"|"position"|"size"
- `includeStats`: Statistical analysis
- `maxSamples`: Samples per group
- `pageId`: Limit to page
